- *IRS tax-exempt associations:* 501(c) HOAs/condos only (NTEE L50 or association name); 1120-H filers absent
- *county/city HOA inventories:* county/city inventories, not a statewide registry — absence means nothing
- *corporate registry:* CID types 62/69/72 kept regardless of name; other types name-gated. Word search only, so a small unnamed tail is possible.
- *statewide judgment liens:* Personal-property judgment liens filed with the SOS; county-recorder abstracts of judgment are not covered.

**Liens / recorded documents**

- [County recorder — official records](https://www.counties.org/) — Assessment liens (Civ. Code 5675) are recorded with the county recorder. Search the grantor/grantee index by the association's name.

**Corporate record**

- [California Secretary of State — bizfile](https://bizfileonline.sos.ca.gov/search/business)

## Not freely accessible

- SOS corporate bulk data — paid media request
- LA County recorder index — bulk sold under fee agreement
- County recorder judgment/assessment lien indexes — no free bulk index; LA sells under fee agreement

```bash
./venv/bin/python -m hoaspy.collect.registries.get_gov_layers --state CA

./venv/bin/python -m hoaspy.collect.courts.get_courts            # nationwide; checkpointed
./venv/bin/python -m hoaspy.build.build_site
./venv/bin/python -m hoaspy.build.build_map
./venv/bin/python -m hoaspy.build.build_seo --base-url https://hoaspy.com
./venv/bin/python -m hoaspy.build.make_states_md   # refresh this page
```

Collectors take `--no-upload` where they can push to S3; the mirror is pushed explicitly with `./scripts/s3_push_all.sh` ([S3.md](../S3.md)). How to add a source: PIPELINE.md.
