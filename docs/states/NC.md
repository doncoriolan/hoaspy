## Source configuration

`gov_layers/NC.yml` — 4 layers for `hoaspy.collect.registries.get_gov_layers`:

- `arcgis` — NC OneMap statewide parcels (NC CGIA) — association-owned parcels, owner name + mailing address ([page](https://www.nconemap.gov/pages/parcels))
- `arcgis` — City of Charlotte — Neighborhood Organization Contact List (HOA / neighborhood associations) ([page](https://data.charlottenc.gov/datasets/charlotte::neighborhood-organization-contact-list-nocl-2))
- `arcgis` — City of Raleigh — Neighborhood Registry (HOA-named entries, home counts) ([page](https://data.raleighnc.gov/datasets/ral::raleigh-neighborhood-registry-3))
- `arcgis` — City of Asheville — Neighborhood Organizations (association-named entries) ([page](https://data-avl.opendata.arcgis.com/))

`site/counties.json` — 100 counties in the county picker, clerk web domain known for 2 (used by the "Google the county clerk" link).

## Collect and rebuild

```bash
./venv/bin/python -m hoaspy.collect.registries.get_gov_layers --state NC
./venv/bin/python -m hoaspy.collect.registries.get_irs_bmf --state NC
./venv/bin/python -m hoaspy.collect.courts.get_courts            # nationwide; checkpointed
./venv/bin/python -m hoaspy.build.build_site
./venv/bin/python -m hoaspy.build.build_map
./venv/bin/python -m hoaspy.build.build_seo --base-url https://hoaspy.com
./venv/bin/python -m hoaspy.build.make_states_md   # refresh this page
```

Collectors take `--no-upload` where they can push to S3; the mirror is pushed explicitly with `./scripts/s3_push_all.sh` ([S3.md](../S3.md)). How to add a source: PIPELINE.md.
