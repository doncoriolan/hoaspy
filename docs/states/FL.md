## Trial courts

Collected per association name from the state's own court portals (best-effort: name-match recall, per-query caps — see [COURTS.md](../COURTS.md)):

- `fl_broward` — Broward County Clerk of Courts — eCaseView (business-name search, Civil) (Broward, anonymous) → `courts/trial_fl_broward.jsonl`; run `./venv/bin/python -m hoaspy.collect.courts.get_state_courts --portal fl_broward`.
- `fl_hillsborough` — Hillsborough County Clerk — HOVER case search (business name) (Hillsborough, anonymous) → `courts/trial_fl_hillsborough.jsonl`; run `./venv/bin/python -m hoaspy.collect.courts.get_state_courts --portal fl_hillsborough`.
- `fl_miamidade` — Miami-Dade Clerk — Commercial Data Services Civil FTP feed; needs the purchased Civil folder staged under `.cache/miamidade_civil/raw/` → `courts/trial_fl_miamidade.jsonl`; run `./venv/bin/python -m hoaspy.collect.courts.records_miamidade_civil`.

**Liens / recorded documents**

- [Broward County Official Records](https://officialrecords.broward.org/AcclaimWeb) — Broward County — Search by name; document types 'Lien' and 'Lis Pendens'. HOA Spy indexes this county in full.
- [Miami-Dade Clerk — Official Records](https://onlineservices.miamidadeclerk.gov/officialrecords/) — Miami-Dade County — Search by party name; HOA Spy indexes this county.
- [Your county's official records](https://www.flclerks.com/page/CourtRecords) — Claims of lien and lis pendens are recorded with the clerk of court as county recorder.

**Corporate record**

- [Florida Division of Corporations — Sunbiz](https://search.sunbiz.org/Inquiry/CorporationSearch/ByName)

**HOA registry**

- [Florida DBPR — condominium & cooperative lookup](https://www.myfloridalicense.com/wl11.asp?mode=0&SID=) — Registration status, units and management for condos, co-ops and timeshares (not HOAs).

## Collect and rebuild

```bash
./venv/bin/python -m hoaspy.collect.registries.get_records --state FL --no-upload
./venv/bin/python -m hoaspy.collect.registries.get_irs_bmf --state FL
./venv/bin/python -m hoaspy.collect.liens.get_liens --no-upload
./venv/bin/python -m hoaspy.collect.liens.get_miamidade_liens --no-upload
./venv/bin/python -m hoaspy.collect.courts.get_courts            # nationwide; checkpointed
./venv/bin/python -m hoaspy.collect.courts.get_state_courts --portal fl_broward
./venv/bin/python -m hoaspy.collect.courts.get_state_courts --portal fl_hillsborough
./venv/bin/python -m hoaspy.collect.courts.records_miamidade_civil
./venv/bin/python -m hoaspy.build.build_site
./venv/bin/python -m hoaspy.build.build_map
./venv/bin/python -m hoaspy.build.build_seo --base-url https://hoaspy.com
./venv/bin/python -m hoaspy.build.make_states_md   # refresh this page
```

Collectors take `--no-upload` where they can push to S3; the mirror is pushed explicitly with `./scripts/s3_push_all.sh` ([S3.md](../S3.md)). How to add a source: PIPELINE.md.
