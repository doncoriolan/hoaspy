# Arizona (AZ)

_Generated by `hoaspy.build.make_states_md` from `coverage.json` (updated 2026-10-02), `state_sources.yml`, `gov_layers/`, the trial-court adapters and `site/portals.json` — edit those, not this page. Index: [STATES.md](../STATES.md)._

**Coverage tier:** State-level data — HOA registry, corporate registry with status, complaint data, or county/city HOA inventories. Every state also has nationwide federal-docket and appellate-opinion coverage from CourtListener. Reports on the site state their own coverage limits per community.

- *IRS tax-exempt associations:* 501(c) HOAs/condos only (NTEE L50 or association name); 1120-H filers absent
- *HOA/condo registry:* Associations named in developer subdivision Public Reports (A.R.S. 32-2183), not a registry: only subdivisions registered since the cut-off year, and only where the report names the HOA. City/ZIP are the subdivision's town, from the report's location and local-services addresses (town-level placement).

**Liens / recorded documents**

- [Maricopa County Recorder](https://recorder.maricopa.gov/recording/document-search.html) — Maricopa County — Search recorded documents by name; assessment liens list the association as grantee.

**Corporate record**

- [Arizona Corporation Commission — eCorp](https://ecorp.azcc.gov/EntitySearch/Index)

**HOA registry**

- [ADRE — HOA dispute process](https://azre.gov/) — Petitions filed against an HOA with the Department of Real Estate.

## Not freely accessible

- ACC eCorp bulk — paid extracts
- Maricopa recorder bulk — paid subscription
- ADRE 'HOA public database' — no longer exists (2026-09-02): ADRE's Public Database was rebuilt as MVC with no HOA module; ADRE does not regulate HOAs and A.R.S. 33-1256/33-1807 create no registry

## Collect and rebuild

```bash
./venv/bin/python -m hoaspy.collect.registries.get_az_adre
./venv/bin/python -m hoaspy.collect.registries.get_irs_bmf --state AZ
./venv/bin/python -m hoaspy.collect.courts.get_courts            # nationwide; checkpointed
./venv/bin/python -m hoaspy.build.build_site
./venv/bin/python -m hoaspy.build.build_map
./venv/bin/python -m hoaspy.build.build_seo --base-url https://hoaspy.com
./venv/bin/python -m hoaspy.build.make_states_md   # refresh this page
```

Collectors take `--no-upload` where they can push to S3; the mirror is pushed explicitly with `./scripts/s3_push_all.sh` ([S3.md](../S3.md)). How to add a source: PIPELINE.md.
